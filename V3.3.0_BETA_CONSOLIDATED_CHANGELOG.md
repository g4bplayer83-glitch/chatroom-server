# DocSpace v3.3.0 BETA — Consolidated Discord + XP Rebuild

Cette build remplace les révisions R2 / R3 / R3.1 / R3.2 par une seule base consolidée.

## Progression
- L’XP est la seule ressource de progression.
- XP: messages, réactions, vocal, bonus quotidien et missions.
- Missions quotidiennes: messages, réactions, vocal.
- Classement XP conservé.
- Rôles de niveau conservés.

## Cosmétiques par niveau
- Niveau 0: Discord, Retro Discord, AMOLED.
- Niveau 2: Bleu Nuit.
- Niveau 3: pseudo Glow.
- Niveau 4: Rouge, Jaune, Deep Purple.
- Niveau 7: pseudo Gradient + thèmes roses.
- Niveau 10: Orange + Forest.
- Niveau 12: pseudo Néon.
- Niveau 20: Theme Lab personnalisé.

## Retiré
- Monnaie banane.
- Boutique bananes / promotions / conversion XP.
- Cookie Clicker et auto-clicker.
- Casino.
- Mini-jeux intégrés et classement mini-jeux.
- Missions liées aux mini-jeux.

Les anciennes données de progression XP sont conservées et les champs legacy inutilisés sont simplement ignorés.
