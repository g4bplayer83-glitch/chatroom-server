# DocSpace v3.3.0 BETA R4 — Discord UI Remake

Cette révision part de la base consolidée XP et ne supprime aucun système supplémentaire.

## Corrigé
- Structure HTML du panneau outils mobile réparée.
- Barre d’écriture replacée hors des overlays et maintenue visible.
- Menus `•••` des messages repositionnés au niveau de la fenêtre pour éviter les superpositions.
- Le menu global du header masque temporairement les actions flottantes des messages.

## Interface
- Rail gauche simplifié pour un seul serveur : Accueil/DM, DocSpace, Paramètres.
- Timeline et actions de messages remaniées façon Discord.
- Maintenir Shift sur un message affiche les actions avancées ; `•••` reste disponible.
- DM en espace deux colonnes sur PC, vue plein écran adaptée sur mobile.
- Amis, Galerie et fenêtres internes recentrés légèrement vers le haut.
- Panneau Admin converti en centre de commande à navigation latérale.

## Admin
- Nouvelle vue d’ensemble avec utilisateurs en ligne, vocal, salon et état client.
- Actions rapides : statistiques, diffusion, annonce, mode lent, logs, cloud.
- Contrôle serveur privé/code d’accès remis dans le panneau.
- Gestion XP rapide depuis la vue d’ensemble.
