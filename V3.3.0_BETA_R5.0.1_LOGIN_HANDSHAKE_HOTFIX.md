# DocSpace v3.3.0 BETA — R5.0.1 Login Handshake Hotfix

- Fixed login getting stuck on "Validation de la session" / "Le serveur répond, mais la session n’a pas été validée".
- Removed the dead `setupGameSocketHandlers()` call left behind after the old mini-game system was removed.
- Optional UI modules (admin, voice, realtime sync, feature listeners, R5 UI) can no longer abort the core `user_join` handshake.
- `user_join` is always emitted even if an optional module fails during setup.
- Boot-freeze protections from the stable R5 build are preserved.
