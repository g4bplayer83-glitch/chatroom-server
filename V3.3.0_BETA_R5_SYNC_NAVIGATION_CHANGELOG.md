# DocSpace v3.3.0 BETA — R5 Sync + Navigation + Overlay Rebuild

## Interface / navigation
- Messages privés transformés en vraie page Home façon Discord : le serveur et ses colonnes disparaissent pendant la vue DM.
- Amis transformé en vraie page Home, cohérente avec la navigation DM.
- Gestion centralisée des couches (`z-index`) : une image ouverte depuis la galerie/stockage ou les DMs passe toujours au-dessus du panneau d'origine.
- Fenêtres internes recentrées et scrollables sans chevauchement.
- Indicateur de frappe refait façon Discord avec avatar, pseudo et animation à trois points au-dessus du compositeur.

## Synchronisation
- Les listeners XP / amis / favoris / présence / vocal sont installés avant le `user_join` afin d'éviter les événements perdus au chargement.
- Chaque panneau important possède maintenant une requête de resynchronisation explicite à l'ouverture ou après connexion.
- DMs : le serveur devient source de vérité avec `dm_sent`, `dm_received`, historique normalisé et rafraîchissement des conversations.
- Amis : recherche de pseudo insensible à la casse, demandes croisées, mise à jour immédiate des deux comptes.
- Présence : récupération explicite de l'historique et notifications join/leave hors du chat.
- Typing : filtrage serveur par salon actif.
- Favoris : le serveur retrouve le vrai message par son ID avant de le sauvegarder.

## XP / cosmétiques
- Payload XP enrichi avec les thèmes réellement débloqués.
- Les cartes de récompenses débloquées sont utilisables et mènent aux thèmes correspondants.
- Les styles de pseudo continuent de suivre les niveaux XP.

## Vocal
- Ajout d'un snapshot `voice_sync_request` / `voice_sync_snapshot` pour réparer une vue vocale après reconnexion ou désynchronisation.
- Nettoyage du peer WebRTC lorsqu'un utilisateur change de salon vocal.
- Reconstruction des peers manquants avec initiateur déterministe pour réduire les connexions doubles.
- Interface vocale rapprochée du style Discord.

## Patch notes
- Historique complet des anciennes versions restauré à partir des données historiques DocSpace.
- Les anciennes fonctions aujourd'hui retirées restent listées uniquement comme archive dans les patch notes.
