# DocSpace 3.4.0 Beta — 5 septembre 2026

## Interface

- Nouvelle couche visuelle sombre et cohérente pour le chat, les formulaires, les salons, les modales et l’Arcade.
- Messages système transformés en cartes compactes pour réduire le bruit dans le fil.
- Responsive mobile et prise en charge de `prefers-reduced-motion`.

## Messages privés

- Espace trois colonnes sur ordinateur : conversations, historique et fiche du membre.
- Messages présentés comme un vrai fil de discussion avec avatar, auteur et heure.
- Navigation mobile conversation/liste conservée.
- Historique, pièces jointes, présence et profil existants réutilisés.

## Comptes et sécurité

- Création de compte avec email facultatif.
- Connexion avec le pseudo ou l’adresse email.
- Modification de l’email avec confirmation du mot de passe actuel.
- Changement de mot de passe depuis les paramètres.
- PBKDF2 renforcé à 210 000 itérations avec migration transparente des anciens comptes.
- Limitation des tentatives de connexion.
- Mot de passe administrateur retiré du code client et validé par le serveur.
- Clés Gemini et Giphy retirées du dépôt et déplacées vers les secrets Fly.io.
- Accès HTTP bloqué pour le code serveur, les données de comptes et les fichiers de configuration.
- Types de fichiers exécutables interdits à l’upload et en-têtes HTTP de sécurité ajoutés.

## DocSpace Plus et emojis

- Activation sans paiement à l’aide d’un code unique défini dans `DOCSPACE_PLUS_CODES`.
- Ajout et suppression d’emojis PNG/JPG/WEBP/GIF par les comptes Plus.
- Utilisation des emojis dans les messages avec `:nom:`.

## Vocal, vidéo et Arcade

- Conservation du vocal WebRTC P2P, du choix des périphériques et du Push-to-Talk.
- Nouvelle page Regarder ensemble utilisant le lecteur YouTube officiel synchronisé par salle.
- Pause Tetris avec la touche `P` réparée.

## Fly.io

- `app = "docspace"` ajouté dans `fly.toml`.
- Volume persistant `docspace_data` conservé sur `/data`.
- Procédure de création du volume, configuration des secrets et déploiement documentée dans le README.
