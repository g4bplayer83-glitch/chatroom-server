# DocSpace v3.3.0 BETA — R5 Stable Features + Boot Freeze Fix

This build keeps the R5 Home/Sync feature set and applies the boot strategy that proved stable in R4.

## Startup reliability
- No R3/R4/R5 MutationObserver or UI polling before a validated `user_join_ready`.
- No automatic socket/reconnect attempt on page load.
- Socket.IO reconnection is disabled; DocSpace reconnect logic is gated behind a previously validated login.
- Old client-only PIN gate is disabled; real server access-code input remains supported.
- Dead shop promo timer removed.
- Session is stored only after a validated join.

## R5 features retained
- DM and Friends Home navigation.
- Layer / image overlay manager.
- Friends, DM, presence, bookmark, XP and voice recovery socket listeners.
- Per-channel typing recovery.
- XP reward actions and Theme Lab gating.
- Voice peer recovery and R5 voice UI.
- Historical patch notes UI.
