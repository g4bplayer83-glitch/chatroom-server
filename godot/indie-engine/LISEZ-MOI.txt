AMONG FUNK v0.1.0 - INSTALLATION ANDROID AUTOMATIQUE

1. Extrayez entierement ce ZIP.
2. Lancez INSTALLER-ANDROID-AUTOMATIQUE.bat.
3. Indiquez le dossier Among Funk contenant project.godot.
4. Glissez l'executable Godot 4.7.2 dans la fenetre si demande.
5. Tapez OUI uniquement si vous acceptez la licence du SDK Android.

Le programme verifie et installe :

- les vrais modeles Android Godot 4.7.2 dans le dossier utilise par Godot ;
- Eclipse Temurin JDK 17 avec Winget s'il est absent ;
- les outils SDK Android officiels et les composants recommandes ;
- les chemins Java SDK et Android SDK dans Godot ;
- les variables JAVA_HOME, ANDROID_HOME et ANDROID_SDK_ROOT.

Il peut ensuite compiler directement :

export\Among-Funk-v0.1.0-Android.apk

IMPORTANT

- Fermez les autres fenetres Godot avant la compilation finale.
- Les telechargements peuvent depasser 1 Go.
- Le script utilise uniquement les distributions officielles Godot, Google Android
  et Eclipse Temurin/Winget.
- Une sauvegarde des parametres Godot est creee avec l'extension
  .among-funk-backup avant leur modification.
- Le projet reste en version 0.1.0.
